# Style Card — Calligraffiti

**ID:** calligraffiti | **Version:** 1.0.0  
**Primary axis:** Hybrid letterform / calligraphic movement grammar  
**Maturity:** Draft. The term and broad hybrid concept are documented; templates are NIGHTSHIFT design studies, not a claim to represent all calligraffiti traditions.

## Definition and intent
Calligraffiti combines calligraphic script traditions and graffiti lettering practices. It can prioritize text, gesture, form, colour or message in different ways. It is not simply a graffiti word with a few calligraphic swashes. The chosen script tradition and writing logic must be named where known.

## Templates

### T1 — Broad-Nib Calligraffiti
**Intent:** strong thick/thin contrast generated by a consistent broad-edge logic, combined with graffiti-scale composition.  
**Construction:** choose a nib-angle model; derive contrast consistently; build a word skeleton; adapt spacing for scale; keep terminals and joins coherent.  
**Parameters:** nib angle, contrast ratio, x-height, terminal cut, spacing, scale adaptation.  
**Guardrails:** do not claim actual ductus from static output; avoid arbitrary thick/thin changes.  
**Tests:** ECHO, RUHR, KRAFT.

### T2 — Pointed / Brush Calligraffiti
**Intent:** elastic strokes with tapered entries, exits and expressive pressure variation.  
**Construction:** model each stroke as a controlled gesture; separate main letter strokes from flourishes; preserve letter identity; keep overlaps deliberate.  
**Parameters:** pressure range, taper, curve tension, gesture amplitude, flourish budget.  
**Guardrails:** flourishes cannot replace missing letter anatomy; document invented movement rules.  
**Tests:** NOVA, SOUL, MIND.

### T3 — Script-Hybrid Graffiti
**Intent:** combine a named calligraphic structural vocabulary with graffiti composition and scale.  
**Construction:** choose a documented script reference; identify its core letter skeletons and terminals; translate selected features into original glyphs; add graffiti composition only after the script base is coherent.  
**Parameters:** script feature mix, angularity, contrast, extension budget, composition density.  
**Guardrails:** identify cultural/script references accurately; avoid sacred or culturally specific forms as generic decoration; do not copy a living calligrapher's signature style.  
**Tests:** same fictional word in base script study and hybrid study; compare feature retention.

## Structural separation
Every output labels:
1. Script reference / source tradition.
2. Calligraphic stroke logic (authored model, not inferred ductus).
3. Graffiti-specific composition choices.
4. Rendering treatments.

## Failure modes
- SWASH_OVERLOAD — decorative flourishes overpower text.
- FAKE_CALLIGRAPHY — contrast has no consistent writing logic.
- SCRIPT_BLUR — source traditions mixed or mislabeled.
- GRAFFITI_STICKER — generic graffiti effects added to unrelated script forms.
- CULTURAL_ORNAMENT — culturally specific forms used without context.

## Acceptance tests
- At least one template passes without colour or texture.
- Thick/thin logic remains consistent across diagonals and curves.
- Main strokes and flourishes are separately inspectable.
- Script source and adaptation decisions are documented.
- Practitioner/editor review for culturally specific references.

## Evidence and inference
**Source-supported:** museum education material describes Calligraffiti as a combination of calligraphy, play with letters and graffiti; contemporary scholarship describes shared concerns with rhythm, proportion, scale and balance.  
**NIGHTSHIFT inference:** T1–T3 and parameter model.  
**Open:** the term spans diverse practices; a single universal grammar would be misleading.
