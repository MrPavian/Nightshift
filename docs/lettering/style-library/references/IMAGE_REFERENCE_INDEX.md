# Image Reference Index — External Graffiti Alphabets

Policy: link to external pages; do not copy image files into the repository without item-level rights clearance. Analyze and synthesize original designs; do not trace or clone.

## R1 — GraffSpace A–Z
https://www.graffspace.com/de/graffiti-alphabet
A–Z sheets described in 3D, Wildstyle, Bomb, Tag, Bubble, shadow and Gothic. Useful for broad alphabet discovery. Site describes downloadable PNGs for drawing/printing, but that is not a NIGHTSHIFT commercial redistribution license. Inspect externally only.

## R2 — Graffiti-Letters.com A–Z in twelve styles
https://graffiti-letters.com/letters/
Same letter can be compared across styles and linked tutorials. Site's personal-project permission is not a blanket repository/commercial license. Link and analyze; do not copy pending explicit rights confirmation.

## R3 — Graffiti Art: Bubble, Block and Angular
https://www.graffitiart.co/styles/
Three complete alphabet families with explicit studio parameters for weight, slant and terminals. Useful controlled comparison; not historical authority.

## R4 — Zumola: Block and Bubble practice sheets
https://zumola.com/drawing-practice/draw-graffiti-alphabet-letters/
Construction-focused practice sheets and answer keys. Verify asset terms before reuse.

## R5 — Zumola: Block, Bubble and Wildstyle
https://zumola.com/drawing-practice/draw-graffiti/
Discusses skeletons, stroke weight, counters and deliberate interlocking/extensions. Treat measurements as source-specific examples.

## R6 — GraffSpace style guide
https://www.graffspace.com/blog/graffiti-alphabet
Five A–Z categories and drawing discussion. Use for discovery and comparison; verify terms and rights independently.

## Visual coding worksheet
For each inspected reference record: reference ID; exact URL/access date; letters visible; source's claimed style label; observed silhouette; construction features; composition features; rendering features; rights status; original NIGHTSHIFT abstraction; confidence.

Do not claim full A–Z coverage if only a partial sample was inspected. Record unavailable or unreadable letters rather than filling gaps by assumption.
