# Style Comparison Matrix — Initial A Test

Purpose: ensure that the same letter differs through construction, not decoration.

## 1. Controlled comparison

Use the same uppercase A skeleton family and artboard dimensions, but allow each grammar to alter the silhouette. Render black silhouettes on a plain light background before adding finish.

| Property | Bubble | Block / Blockbuster | Wildstyle |
|---|---|---|---|
| Primary dimension | Letterform grammar | Letterform grammar + optional format context | Composition grammar affecting glyphs |
| Skeleton | Preserved, then expanded into rounded mass | Preserved, then thickened/squared | Traceable base, selectively transformed |
| Outer contour | Inflated continuous curves | Straight/angular robust contour | Directional extensions and planned interlocks |
| Corners | Softened by role | Square, clipped or minimally softened | Mixed; sharp cuts only when motivated |
| Stroke mass | Heavy, rounded | Broad and stable | Variable by structural role and flow |
| A counter | Protected; may become smaller but remains open | Clear and robust | Protected as negative-space channel |
| Terminals | Rounded/bulbous | Flat/squared/cut | Directional extensions only when anchored |
| Word spacing | Compact; controlled contact/overlap | Tight block rhythm | Planned through relationship graph |
| Complexity source | Inflation and massing | Geometry and proportion | Connections, flow and abstraction |
| Finish dependence | Must read without fill effects | Must read without 3D | Must read monochrome without chrome/colour |
| Main failure | Balloon-font uniformity | Generic rectangle | Random arrows / accidental collisions |

## 2. A-specific NIGHTSHIFT invariants
- Preserve two recognizable diagonal legs and an apex or intentional apex variant.
- Preserve a crossbar or explicitly authored alternative junction.
- Keep the counter/opening topologically clear.
- Maintain balanced leg mass unless asymmetry is an intentional variant.
- Outline, extrusion and highlights must not masquerade as structural components.

## 3. Required views per style
1. Skeleton: centreline / structural guide only.
2. Construction: stroke body, counter and component junctions.
3. Final monochrome silhouette: no colour, shadow, chrome, texture or effects.
4. Optional finish view, clearly separated from letterform construction.

## 4. Evaluation
Score 0–4: structural distinction, recognizability, counter openness, consistency, balance, originality and independence from finish effects. Fail if styles differ only by colour, outline, shadow, extrusion, drips or decorative arrows.

## 5. Follow-up pair/word tests
AB, AR, BA, RA, BOMB, GHOST, KRAZE, MIND, NYX, RISK and SQUE. Wildstyle must classify every join as attachment, overlap, crossing, continuation, near-contact or shared contour.
