# NIGHTSHIFT Style Reference Library

Version 1.0.0 — initial reference release. Three core cards drafted; practitioner review pending.

## Purpose
A source-aware, construction-first library for original NIGHTSHIFT graffiti lettering. It is not a moodboard. Each style is translated into observable form rules, parameters, constraints, failure states and acceptance tests.

## Core modelling rule
Do not encode styles as one flat list of mutually exclusive presets. Keep separate axes:
1. Letterform grammar — how an individual glyph is constructed.
2. Composition grammar — how glyphs relate in a word or piece.
3. Practice / format context — tag, throw-up, piece, panel, wholecar, etc.
4. Rendering treatment — fill, outline, inline, depth, chrome, texture, drips.

## Evidence labels
Every rule is Source observation, Cross-source synthesis, NIGHTSHIFT design inference, or Open question. Do not present engineering rules as historical facts.

## Rights and originality
External reference sheets are discovery aids. Public visibility is not a reuse license. Do not commit third-party images without item-level rights clearance. Do not clone identifiable writers, crews, tags, signatures or existing pieces. Build original fictional letterforms.

## First implementation sequence
1. Practitioner/editor review of the three cards.
2. Create monochrome A comparisons in Bubble, Block and Wildstyle.
3. Extend to A, B, G, R, S, W, X, Y and Z.
4. Expand to full uppercase/lowercase only after the test set passes.
5. Add further style cards based on research and generator needs.

The Academy's nine-panel sheet is the educational presentation format. This library is the deeper technical reference behind its form-character and graffiti-transfer panels.
