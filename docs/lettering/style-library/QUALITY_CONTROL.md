# Style Library — Quality Control

## 1. Evidence discipline
Separate source-supported observations, cross-source synthesis, NIGHTSHIFT design inference and open questions. Never present engineering parameters as historical facts or call a generated preset historically authentic.

## 2. Review sequence
1. Skeleton.
2. Stroke body / mass.
3. Counter, aperture and negative spaces.
4. Outer contour and terminals.
5. Word spacing and relationships.
6. Finish effects.

If the silhouette fails before step 6, effects must not hide the defect.

## 3. Universal acceptance gates
- Glyph identity remains inspectable.
- Counter/aperture topology is preserved or intentionally documented.
- Stems, bars, bowls, diagonals and junctions are coherent.
- Width and height vary by glyph; no forced identical advance widths.
- Style difference is visible in monochrome silhouette.
- Rules remain consistent across representative glyphs.
- No identifiable writer, crew, tag, signature or existing piece is copied.
- External assets have item-level rights clearance before repository inclusion.
- Output is an original NIGHTSHIFT design study.

## 4. Style-specific gates

### Bubble
- Curvature changes the actual contour.
- Inflation is not uniform circular expansion.
- Counters remain open; necks/bridges remain strong.
- Glyph identities survive rounding.
- No reliance on drips/highlights/outline to signal the style.

### Block / Blockbuster
- Straight/angular geometry is visible in front-face silhouette.
- Counters remain generous.
- Bars and stems have deliberate alignments.
- Word block is coherent without mechanically equalizing every glyph.
- Flat silhouette works without extrusion.

### Wildstyle
- Every structural extension links to a glyph component/anchor or is labelled decorative.
- Each join has a declared relationship type.
- Crossings have clear layer order and continuity.
- Negative-space channels remain protected.
- Directional flow is coherent across the word.
- Complexity is not measured by arrow count or illegibility.

## 5. Scoring
| Score | Meaning |
|---|---|
| 0 | Fails / absent |
| 1 | Weak; major structural issue |
| 2 | Partial; recognizable but inconsistent |
| 3 | Pass; clear and consistent |
| 4 | Strong; distinctive, controlled and well evidenced |

Minimum pass: no score below 3 for structural distinction, glyph identity, negative-space integrity and style consistency.

## 6. Failure flags
- COSMETIC_ONLY — differences are only colour/effects.
- COUNTER_COLLAPSE — negative space closes unintentionally.
- GENERIC_GLYPH — identity lost through a generic template.
- UNANCHORED_EXTENSION — extension has no structural origin.
- UNDECLARED_CROSSING — intersection lacks relationship/layer order.
- STYLE_AXIS_COLLAPSE — letterform, context and rendering are conflated.
- RIGHTS_UNVERIFIED — source asset has no verified reuse status.

A card remains draft until practitioner/editor review and testing across a representative glyph set.
